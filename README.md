# Meeting Recorder

Легка програма для запису аудіо онлайн-дзвінків (Zoom, Meet, Teams, Telegram, браузер) і їхньої **локальної транскрипції**: хто що сказав, із часом.

- **Лівий канал:** мікрофон (ви).
- **Правий канал:** системний звук (співрозмовники).
- **Формат:** Ogg Opus, 16 кГц, ~32 кбіт/с (≈ 8–15 МБ на годину).
- **Один дзвінок — один файл** `part_0001.ogg`, навіть після паузи чи сну комп'ютера. Ділити на частини можна лише в консольній версії: `recorder start --part-minutes 10`.
- **Для прослуховування** поруч пишеться `listen.ogg`: обидві сторони змішані в моно, тож чути всіх в обох вухах (≈ 5–8 МБ на годину). Для транскрипції беріть `part_*.ogg`, де канали розділені.
- **Транскрипція на цьому комп'ютері:** `transcript.txt` (діалог з часом: хто говорить — ім'я або «Participant N»), `transcript.srt` (субтитри до `listen.ogg`) і `transcript.json`. Аудіо нікуди не надсилається.
- **Стійкість до збоїв:** якщо програма впаде, втрачається не більше ~1,5 с запису.

> **Юридичне нагадування.** Ви відповідаєте за отримання згоди всіх учасників розмови на запис відповідно до законодавства (GDPR, місцеві закони).

## Встановлення

Готові інсталятори є в артефактах [GitHub Actions](../../actions) (`meeting-recorder-macos-arm64`, `meeting-recorder-windows-x64`):

- **macOS 13+:** `Meeting Recorder_<версія>_aarch64.dmg`. Перетягніть програму в «Програми»; перший запуск — правий клік → «Відкрити».
- **Windows 10/11:** `meeting-recorder_<версія>_x64-setup.exe`. Встановлюється для поточного користувача, права адміністратора не потрібні.

Відкрийте **Meeting Recorder** з «Програм» (macOS) або меню «Пуск» (Windows): **Start recording → Stop → Show in Finder** (інтерфейс англійською).

## Транскрипція

1. **Settings → Transcription → Download speech models.** Один раз. Перервану закачку можна продовжити, файли перевіряються за SHA256.
   - macOS, якість **Best** (за замовчуванням): ≈ 3,5 ГБ завантаження і на диску.
   - Якість **Fast** і Windows: ≈ 2,6 ГБ.
   - Якщо стоїть одна з попередніх моделей Parakeet, у налаштуваннях буде **Update speech models**: нова модель точніша, стара видаляється.
2. Після кожного запису транскрипція запускається сама (вимикається перемикачем «Transcribe automatically»). Або натисніть **Transcribe** у картці «Last recording».
3. **Вікно.** Ліворуч навігація: **Record**, **Recordings**, внизу **Settings**. **Record** і **Settings** займають вікно однією колонкою. У **Recordings** ліворуч список записів, а праворуч розшифровка вибраного: час, хто говорить (у кожного свій колір), текст, який можна виділяти й копіювати. Є пошук з підсвіткою («Find in transcript»), **Copy all** і **Open file** (`transcript.txt`).
4. **Recordings** — один список записів, найновіші зверху: дата, тривалість, стан транскрипції. Спершу читаються 50 записів, далі ще по 50, коли докрутиш до кінця. Одразу відкрито найновіший запис або той, що ти вибрав раніше. Клік по будь-якому місцю рядка показує його розшифровку: угорі учасники («Participants  Григорій · Катя · …»), далі репліки. Біля запису є **Transcribe** (кілька записів стають у чергу), прогрес зі **Stop**; кнопка з папкою (Finder / Explorer) з'являється під курсором. **View** під останнім записом на **Record** відкриває його в **Recordings**. **Назва запису:** олівець біля заголовка розшифровки (або подвійний клік по заголовку) — вписати назву, Enter зберігає, Esc скасовує; порожня назва повертає дату. Назва показується в списку, у розшифровці й на **Record**; зберігається у `title.txt` у теці запису, а сама тека не перейменовується (за її назвою впорядковано список). **Імпорт:** **Import…** угорі розділу **Recordings** (або просто перетягнути файли у вікно) додає аудіо чи відео як запис і, як після дзвінка, розшифровує його: MP3, M4A/AAC, MP4/MOV/M4V, WAV, FLAC, ALAC, Ogg Vorbis, Opus (голосові з Telegram/WhatsApp: `.opus`, `.oga`), AIFF, CAF, MKV. Звук зводиться в моно й іде в канал співрозмовників, тож голоси стають «Participant 1, 2…»; назва запису — ім'я файлу. Година звуку імпортується ≈ за хвилину; файл декодує Symphonia (MPL-2.0). **Видалення:** кошик у заголовку розшифровки відкриває підтвердження: **Delete transcript** (лише текст; аудіо лишається, запис можна розшифрувати знову) або **Delete recording** (уся тека запису). Усе йде в системний Кошик (на Windows — у Корзину), тож видалення можна відкотити. Поки запис іде, розшифровується чи стоїть у черзі, кошика немає. **Імена учасників:** клік по імені в рядку «Participants» — вписати ім'я, Enter зберігає; воно змінюється в усій розшифровці та в `transcript.txt`, `.srt`, `.json` (поле `given`). Порожнє ім'я повертає знайдене в розмові або «Participant N». Нова транскрипція того ж запису визначає учасників заново, тож дані імена тоді треба вписати знову. `transcript.txt` і **Copy all** — лише репліки `[час] Ім'я: текст`, без заголовка; чим і як зроблено розшифровку, записано в `transcript.json`.

Як це працює:

- **Fast** (і єдиний режим на Windows): Parakeet Ultra від Moondream — донавчена NVIDIA Parakeet TDT 0.6B v3 (повна точність, 2,4 ГБ) + silero VAD через sherpa-onnx. Українська, англійська й ще 23 європейські мови, мова визначається сама. Кожен шматок мовлення бере по 0,2 с звуку довкола: так модель не перекручує слова на краях. На реченнях FLEURS це 6,4% помилок українською і 5,2% англійською (Parakeet v3: 7,2% і 5,6%; її INT8-версія: 13,3% і 16,3%). До 3 ГБ пам'яті; швидкість — нижче.
- **Best** (лише macOS): текст пише Whisper large-v3-turbo (whisper.cpp на графічному процесорі, Metal), а Parakeet заповнює те, що Whisper пропустив, і дає англійські фрази. Слова, які Whisper «вигадав» без мовлення, відкидаються. Помітно менше помилок у словах і термінах, але вдвічі довше й до 4 ГБ пам'яті.
- Канали розпізнаються окремо, тож «Me» і «Others» не плутаються. Якщо мікрофон чув співрозмовників із динаміків, ці фрази позначаються як луна й не показуються.
- **Голоси співрозмовників** розрізняються за тембром. Голосові відбитки 3D-Speaker CAM++ (27 МБ) на мовленнєвих вікнах системного звуку, кластеризація. Так само й на твоєму мікрофоні, якщо в нього говорять кілька людей (зустріч у кімнаті): кожен — окремий учасник, твоє ім'я дістається тому, хто говорить найбільше. Луна співрозмовників із динаміків у цьому не бере участі, а голос із менш ніж 25 словами на мікрофоні окремим не вважається. Додає ≈ 1 хв на годину дзвінка. Вимикається перемикачем «Tell voices apart». Дуже короткі репліки («так», «ок») можуть потрапити не тому голосу.
- **Імена.** Твій мікрофон підписаний ім'ям з налаштувань (**Settings → Transcription → Your name**; порожнє — «Participant N»); з розмови воно не вгадується, бо такі здогадки здебільшого були про когось, про кого ти говорив. Кожен голос співрозмовників підписаний ім'ям, якщо розмова його однозначно показує: «Каті, розкажи…» → наступна, хто говорить, — Катя; «Дякую, Роман, за коментар» → Роман той, хто щойно говорив; «мене звати…», «I'm…». Інакше — «Participant 1», «Participant 2»… у порядку появи. Імена беруться зі словника українських та англійських імен у будь-якому відмінку й можуть бути помилковими.
- Коли Mac гріється, транскрипція робить перерви, а коли гарячий — чекає, доки охолоне (у вікні: «resting» / «cooling down»). Текст від цього не змінюється.
- Транскрипція працює в окремому процесі з низьким пріоритетом. Збій чи брак пам'яті там не зачепить запис. Коли починається новий запис, транскрипція зупиняється й потім продовжується з місця зупинки.
- **Швидкість.** «Speed: Gentle» (за замовчуванням) на Mac працює лише на efficiency-ядрах: утричі менше енергії, Mac лишається прохолодним. Година мовлення: Fast ≈ 15 хв, Best ≈ 30 хв (MacBook Air M4). «Speed: Fast» використовує performance-ядра: Fast ≈ 4 хв, Best удвічі швидше, але Mac гріється. Пам'ять до ≈ 2,5 ГБ (Best ≈ 3,5 ГБ) під час роботи, потім звільняється.

## Збірка

Потрібні Rust (stable) і CMake. На Windows також Visual Studio Build Tools з компонентом «Desktop development with C++» і Git Bash.

Один раз зберіть sherpa-onnx (статично, без синтезу мовлення; ≈ 5 хв, на половині ядер з низьким пріоритетом):

```bash
scripts/build-sherpa-onnx.sh
```

Далі:

```bash
cargo build --release -p recorder-cli -p recorder-tray -p recorder-transcriber
```

- `target/release/meeting-recorder` — програма з вікном.
- `target/release/meeting-recorder-transcribe` — транскрибувальник (вікно й консоль запускають його самі; має лежати поруч).
- `target/release/recorder` — консольна версія.
- На Windows файли мають розширення `.exe`.
- На Mac збирати можна холодніше: `taskpolicy -b cargo build --release …` — лише на efficiency-ядрах (довше, але ноутбук не гріється; `nice` цього не робить). Release-профіль має thin LTO: повний LTO не прискорював транскрипцію (важка робота в C++-бібліотеках), а кожне лінкування, зокрема кожного тесту, займало хвилини.

Інсталятор (`.app` + `.dmg` або NSIS `.exe`) з'явиться в `dist/`. Потрібен [cargo-packager](https://github.com/crabnebula-dev/cargo-packager):

```bash
cargo install cargo-packager --version 0.11.8 --locked
cd crates/recorder-tray && cargo packager --release
```

Тести (у release-режимі, бо симуляції довгі):

```bash
cargo test --workspace --release
```

Тести з моделлю (вимкнені за замовчуванням, потрібні модель і тестові записи) описані в `crates/recorder-transcriber/tests/model.rs`.

## Консольна версія

На macOS консольна версія з термінала не отримає дозволу на системний звук, тож для запису користуйтеся застосунком.

```bash
recorder devices                  # список пристроїв
recorder start                    # запис; Ctrl+C — стоп
recorder start --process Zoom.exe # Windows: лише звук Zoom
recorder start --aec on           # придушення луни завжди (auto — лише для динаміків)
recorder verify "<папка сесії>" --wav   # перевірка + me.wav / them.wav
recorder recover                  # закрити сесії після збою
recorder model download           # завантажити моделі (також status, verify, delete)
recorder transcribe "<папка сесії>"     # транскрипція; --threads 4 — швидше, --quality fast|best, --no-voices
```

| | Записи | Логи | Модель |
|---|---|---|---|
| Windows | `Documents\Meeting Recorder\recordings\` | `%LOCALAPPDATA%\Meeting Recorder\logs\` | `%LOCALAPPDATA%\Meeting Recorder\models\` |
| macOS | `~/Documents/Meeting Recorder/recordings/` | `~/Library/Logs/Meeting Recorder/` | `~/Library/Application Support/Meeting Recorder/models/` |

## Структура

```
crates/recorder-core         часова шкала, дрейф, Opus/Ogg, частини, manifest, відновлення (без ОС-залежностей)
crates/recorder-capture      мікрофон (cpal), WASAPI loopback, Core Audio tap, ScreenCaptureKit, дозволи, сон
crates/recorder-app          сесія запису в окремому потоці, повідомлення, налаштування, логи, запуск транскрипції
crates/recorder-cli          консольна програма `recorder`
crates/recorder-tray         програма з вікном `meeting-recorder` (egui)
crates/recorder-transcribe   транскрипція без нативного коду: модель, шматки, діалог, луна, файли, протокол
crates/recorder-transcriber  транскрибувальник `meeting-recorder-transcribe` (sherpa-onnx + ONNX Runtime)
scripts/                     збірка sherpa-onnx
packaging/                   Info.plist, entitlements, іконки, ліцензії
```
